# Third-party software, data and tools

Everything outside this repository's own code that Tetitulz.Pdf was built with, shipped with, or
checked against. Licence texts and the formal notices for shipped components are in
[`NOTICE.md`](NOTICE.md); this file is the wider inventory, for credits and documentation.

Versions of NuGet packages live in one place, [`Directory.Packages.props`](Directory.Packages.props).

Product and project names here are their owners' trademarks, used only to say what was used. None
of their owners endorses, certifies or is affiliated with Tetitulz.Pdf.

**No proprietary colour library ships.** A built-in table of trade-named spot colours with sRGB values
was removed on 2026-10-25 (`NamedColorDatabase`, and `PdfOperations.TryResolveNamedColor(name, out r, g, b)`).
A spot colour is drawn from the file's own `/Separation` alternate, or from an ICC named-colour profile
the caller supplies under their own licence (`TryResolveNamedColor(name, profile, …)`,
`PdfRenderOptions.NamedColorProfile`). Test fixtures name their colorants `SPOT …`.

## 5. Independent checkers used as test oracles

**No test runs any of these.** Their answers were recorded once and are committed beside the tests
(`tests/Tetitulz.Pdf.Core.Tests/Fixtures/IndependentDecodes`, `tests/Tetitulz.Pdf.Base.Tests/Fixtures/IndependentRenders`,
`tests/Tetitulz.Pdf.Base.Tests/Fixtures/WriterCheck`), or replaced by a checker written in the
repository from the standards. The live tools are plugged in only from the git-ignored
`oracle-tests/` folder, to re-record (`TETITULZ_RECORD_INDEPENDENT=1`).

| Tool | What it checked | In the repository now |
|---|---|---|
| qpdf 12.4.2 | Every writer's output structure, both layouts; encryption with either password. Also wrote the object-stream copy of the writer fixture. | `IndependentPdfCheck` (own parser, xref reader, standard-handler decryption); the fixture as a committed file |
| PDFium (via pypdfium2) | Pixels of what the JBIG2, JPEG 2000, CCITT, LZW and RunLength encoders and the halftone TIFF write. | 13 recorded renders, keyed by the stream's SHA-256 (`IndependentImageRender`) |
| Pillow 12.1.1 / OpenJPEG 2.5 | JPEG 2000 and HTJ2K codestreams the encoder and transcoder write. | 116 recorded decodes (`IndependentJpxDecode`) |
| jpylyzer | JP2 container and codestream validity. (Never ran here: not installed.) | `IndependentJp2Check`, from ISO 15444-1 Annex I |
| Python `hashlib`, pyca/cryptography (asn1crypto) | Ed448 CMS signatures. | `IndependentEd448Cms` (own DER, SHAKE256, RFC 8032), pinned to SHAKE256 and Ed448 vectors those two produced |

Local-only scripts moved to `oracle-tests/tools/`: `render_compare.py` (renders against PyMuPDF and
pypdfium2) and `make_jpx_fixtures.py` (writes `JpxLosslessFixtures.cs` through Pillow/OpenJPEG).

and its JavaScript API Reference, and PDFKit.
